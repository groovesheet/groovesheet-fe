## Codebase Patterns
- Auth: Use `useUser()` for `isSignedIn` check, `useAuth()` for `getToken`, both from `@clerk/clerk-react`
- API calls: Use `authenticatedFetch` from `src/utils/api.js` with `getToken` from `useAuth()`
- Login gate: Components receive `onLoginClick` prop from parent (App.js manages LoginModal state)
- API proxy: `/api` prefix is proxied to backend orchestrator via setupProxy.js
- Pricing component is used in LandingPage, MidiConverter, and StemSplitter
